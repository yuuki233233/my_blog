# 1. 进程终止：释放资源

进程终止的本质就是释放系统资源（PCB、代码、数据、打开的文件等）

## 1.2 退出场景

1. 代码跑完，结果正确（退出码 `0`）
2. 代码跑完，结果不正确（退出码 `非0`，不同数字代表不同错误原因）
3. 代码异常终止（被信号杀死，如段错误、除零错误）

我们可以用 `echo $?` 查看上一个命令的退出码。Linux 常见退出码如 `127`（找不到命令）、`130`（被 Ctrl+C 终止）

## 1.3 退出码

退出码可查看最后一次执行命令的状态。程序返回退出码 0 时，表示执行成功。代码返回 1 或 0 以外的任何退出码，都被视为不成功

```bash
[zjh@izj6cd3zr5adf6jnm3mwihz lesson16]$ cat proc.c
#include <stdio.h>
#include <string.h>

int main()
{
    FILE* f = fopen("log.txt", "r");
    if(f == 0) return 1;

    return 0;
}

[zjh@izj6cd3zr5adf6jnm3mwihz lesson16]$ ./proc

[zjh@izj6cd3zr5adf6jnm3mwihz lesson16]$ echo $?
1
```
非正常退出，打印 return 1

也可以查看命令的进程码：
```bash
[zjh@izj6cd3zr5adf6jnm3mwihz lesson16]$ ls v.cpp
ls: cannot access v.cpp: No such file or directory

[zjh@izj6cd3zr5adf6jnm3mwihz lesson16]$ echo $?
2

[zjh@izj6cd3zr5adf6jnm3mwihz lesson16]$ ls v.c
v.c

[zjh@izj6cd3zr5adf6jnm3mwihz lesson16]$ echo $?
0
```
`ls` 没有找到时，进程码返回 2，`ls` 找到时，进程码返回 0

机器返回错误结果都是数字，我们人类想查看返回错误结果，就需要看字符串，对此 C标准库 里的提供了错误信息的字符串

Linux Shell 中的主要退出码：

| 退出码   | 解释                                        |
| ----- | ----------------------------------------- |
| 0     | 命令执行成功                                    |
| 1     | 通用错误代码                                    |
| 2     | 命令或参数使用不当                                 |
| 126   | 权限被拒绝或无法执行                                |
| 127   | 未找到命令或PATH错误                              |
| 128+n | 命令被信号从外部终止或遇到致命错误                         |
| 130   | 通过 `Ctrl+c` 或 `SIGINT` 终止（终止代码 2 或 键盘中断）  |
| 143   | 通过 `SIGTERM` 终止（默认终止）                     |
| 255/* | 退出码超过了` 0-255` 的范围，因此重新计算（超过 255 后，用退出取模） |
- 0：表示命令执行无误
- 1：不被允许操作。如在没有 sudo 权限的情况下
- 130：`SIGINT` 或 `^C` 和 `143`（`SIGTERM`）等终止信号时非常典型的，它们属于 `128+n` 信号，其中 `n` 代表终止码
- 可以使用 `strerror` 函数来获取退出码对应的描述

## 2.3 `exit()` vs `_exit()`

- `_exit(int status)`：纯正的系统调用。直接陷入内核，立刻释放资源，不刷新用户态缓冲区
- `exit(int status)`：C 库函数。它的内部也会调用 `_exit`，但在调用之前会做两件事：
	1. 执行用户通过 `atexit` 注册的清理函数
	2. **刷新所有打开的流（标准 I/O 缓冲区）**

![471](图片/执行exit过程.png)
区别：
- 进程如果 exit 退出的时候，`exit()`，进程退出的时候，会进行缓冲区的刷新
- 进程如果 exit 退出的时候，`_exit()`，进程退出的时候，不会进行缓冲区的额刷新

>[!note]
>测试题：`printf("hello"); _exit(0);` 屏幕上什么都不会打印
>换成 `exit(0);` 则会打印 `hello`
