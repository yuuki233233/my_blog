# 进程终止

进程终止的本质就是释放系统资源，释放进程中申请的相关内核数据结构和对应的数据和代码

## 进程退出场景

进程退出无非三种场景：
1. 代码运行完毕，结果正确
2. 代码运行完毕，结果不正确
3. 代码异常终止
父进程要获取到子进程的信息，也就是进程退出场景的结果

## 进场常见退出方法

正常终止：
1. main函数的返回值，通常表明你的程序的执行情况
	- `return 0;`（代码运行完毕，结果正确）
	- `return !0;`（代码运行完毕，结果不正确，用不同的返回值表明不同的出错原因）
- 调用 exit
- `_exit`

## 进程码

查看上一个进程的进程码：`echo $?`

```bash
[zjh@izj6cd3zr5adf6jnm3mwihz lesson16]$ cat proc.c
#include <stdio.h>
#include <string.h>

int main()
{
    FILE* f = fopen("log.txt", "r");
    if(f == 0) return 1;

    return 0;
}

[zjh@izj6cd3zr5adf6jnm3mwihz lesson16]$ ./proc

[zjh@izj6cd3zr5adf6jnm3mwihz lesson16]$ echo $?
1
```
非正常退出，打印 return 1

也可以查看命令的进程码：
```bash
[zjh@izj6cd3zr5adf6jnm3mwihz lesson16]$ ls v.cpp
ls: cannot access v.cpp: No such file or directory

[zjh@izj6cd3zr5adf6jnm3mwihz lesson16]$ echo $?
2

[zjh@izj6cd3zr5adf6jnm3mwihz lesson16]$ ls v.c
v.c

[zjh@izj6cd3zr5adf6jnm3mwihz lesson16]$ echo $?
0
```
`ls` 没有找到时，进程码返回 2，`ls` 找到时，进程码返回 0
