# 进程创建

## fork函数
在 `Linux` 中 `fork` 函数是非常重要的函数，它从已存在进程中创建一个新进程。新进程为子进程，而原进程为父进程
```c
// 子进程返回0，父进程返回子进程id，出错返回-1
#include <unistd.h>
pid_t fork(void);
```
问题：
1. 为什么要给子进程返回0，父进程返回子进程id
2. 为什么一个函数fork会有两个返回值
3. 为什么一个id即等于0，又大于0
这些问题我们在上一章中，进程的概念中细讲过，这里我就简单回归一下

进程调用 `fork()`，当控制转移到内核中的 `fork()` 代码后，内核做：
- 系统里多了个进程，进程 = 内核数据结构 + 数据，给子进程分配新的内存块和内核数据结构给子进程
- 将父进程部分数据结构内容拷贝给子进程。比如父进程的PCB、地址空间、页表
- 添加子进程到系统进程列表里，所有的进程都是以链表的形式管理的，所有把子进程添加到链表里，或是大O(1)算法里的过期列表中
- `fork` 返回，开始调度器调度

 ![](图片/子进程的创建.png)

当一个进程调用 `fork` 之后，就有两个二进制代码相同的进程。而且它们都运行到相同的地方。但每一个进程都将可以开始执行它们自己代码，如下：
```bash
[zjh@izj6cd3zr5adf6jnm3mwihz lesson17]$ cat fork.c
#include <stdio.h>
#include <unistd.h>
#include <sys/types.h>

int main()
{
    pid_t pid;
    
    printf("Before: pid is %d\n", getpid());
    if((pid = fork()) == -1)
    {
        perror("fork()");
        return 1;
    }

    printf("After: pid is %d, fork reeturn %d\n", getpid(), pid);
    sleep(1);

    return 0;
}

[zjh@izj6cd3zr5adf6jnm3mwihz lesson17]$ ./code
Before: pid is 18404
After: pid is 18404, fork reeturn 18405
After: pid is 18405, fork reeturn 0
```

这里看到三行输出，第一行 before，第二行 after。进程 18404 先打印 before 消息，如何它又打印 after。另一个 after 消息有 10405 打印。注意到进程 10405 没有打印 before，原因如下表：
![](图片/子进程的id打印.png)

所以，`fork` 之前父进程独立执行，`fork` 之后，父子两个执行流分别执行。注意，`fork` 之后，谁先执行用调度器决定。

## fork函数返回值
- 子进程返回0
- 父进程返回的是子进程的pid

## 写实拷贝

父子进程的代码和数据是共享的，当任意一方写入，便以写实拷贝的方式各有一份副本。如下图：
![](图片/写实拷贝.png)
写实拷贝的好处：
1. 通过虚拟地址寻找物理地址，当一个进程不需要执行时，虚拟地址指向的物理地址就只需挂起状态即可（节省内存）
2. 当创建子进程时，父子进程的数据段会变成只读状态，通过只读数据中修改的报错，来拷贝一份副本，将数据的只读改为可读可写（通过只读的报错拷贝副本）
3. 虚拟地址通过页表来查询物理内存，页表可以进行指向的修改，让虚拟地址不直接等于物理地址（减少耦合性）

## fork常规用法

- 一个父进程希望复制自己，使父子进程执行不同的代码段。例如：父进程等待客户端请求，子进程处理请求
- 一个进程要执行一个不同的程序。例如：子进程从 fork 返回后，调用任意函数

## for调用失败的原因

- 系统中有太多进程
- 实际用户的进程数超过了限制
