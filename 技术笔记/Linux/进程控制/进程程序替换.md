# 进程程序替换

## 原理

程序替换过程中，并没有创建新的进程，只是：用新程序的代码和数据覆盖当前进程的代码和数据

- 图表

**替换程序的函数接口，execl()**
```c
int execl(const char* path, const char *arg, ...);
```
1. 替换成功：执行新代码，未执行到的原始代码不存在
2. 替换失败（路劲/命令/参数不正确）：返回-1，只有失败时才有返回值

```c

       int execl(const char *path, const char *arg, ...);
       
       int execlp(const char *file, const char *arg, ...);

                  ..., char * const envp[]);

       int execvp(const char *file, char *const argv[]);
       
       int execvpe(const char *file, char *const argv[],
                   char *const envp[]);
```

### execl接口

```c
int execl(const char* path, const char *arg, ...);
```
execl中，将**参数以链表的方式传替到函数**中，所以 execl 中的 l 就是 list

```c
   int n = execl("/usr/bin/ls", "ls", "-l", "-a", NULL);
```
1. 替换成功：执行新代码，未执行到的原始代码不存在
2. 替换失败（路劲/命令/参数不正确）：返回-1，只有失败时才有返回值

- `const char* path`：进程替换文件路径 + 程序名
- `const char *arg`：执行的命令行
- `...`：命令行参数，但结尾必须以 NULL 结尾
- 如：`int id = execl("bash/usr/bin/ls", "ls", "-a", "-l", NULL);`

#### 如何让进程不被替换

为了让进程不进行替换，就创建子进程来执行 execl
```bash
[zjh@izj6cd3zr5adf6jnm3mwihz lesson17_1]$ cat proc.c
#include <stdio.h>
#include <unistd.h>
#include <sys/types.h>
#include <wait.h>

int main()
{
    printf("程序正在运行中~\n");
    
    if(fork() == 0)
    {
        sleep(1);
        //child
        execl("/usr/bin/ls", "ls", "-l", "-a", NULL);
    }

    waitpid(-1, NULL, 0);
    printf("程序结束终止\n");

    return 0;
}
```

### execlp接口

```c
 int execlp(const char *file, const char *arg, ...);
```
execlp中，p 为 PATH，查找系统命令

```c
execlp("ls", "ls", "-l", "-a", NULL);
```

- `const char *arg`：执行的命令行
- `...`：命令行参数，但结尾必须以 NULL 结尾

### execv接口

```c
 int execv(const char *path, char *const argv[]);
```
execv中，v 为 vector，以指针数组的方式传参

```c
execlp("ls", "ls", "-l", "-a", NULL);
```
-  `const char* path`：进程替换文件路径 + 程序名
- `char *const argv[]`：提供应该命令行参数表，就是一个指针数组

```bash
[zjh@izj6cd3zr5adf6jnm3mwihz lesson17_1]$ cat proc.c

#include <sys/types.h>
#include <wait.h>

int main()
{
    printf("程序正在运行中~\n");
    
    if(fork() == 0)
    {
        sleep(1);
        //child
        
        char *const argv[] = {
            (char*const)"ls",
            (char*const)"-l",
            (char*const)"-a",
```

### execvpe接口

```c
int execvpe(const char *file, char *const argv[], char *const envp[]);
```
-  `const char* file`：执行文件名（因为 execlp 会自动在环境变量 PATH 中查找指定的命令）
- `char *const argv[]`：提供应该命令行参数表，就是一个指针数组
- `char *const envp[]`：环境变量（只会获取全新的环境变量）

```bash
[zjh@izj6cd3zr5adf6jnm3mwihz lesson17_1]$ cat other.cc
#include <iostream>
#include <unistd.h>
#include<cstdio>

int main(int argc, char *argv[], char *env[])
{
    std::cout << "hallo C++" << std::endl;

    for(int i = 0; i < argc; i++)
    {
        printf("argv[%d]: %s\n", i, argv[i]);
    }

    printf("\n");

    for(int i = 0; env[i]; i++)
    {
        printf("env[%d]: %s\n", i, env[i]);
    }

    return 0;
}
```
