# vim 概念
vim 编辑器分为三种模式：命令模式（command mode）、插入模式（insert mode）、末行模式（last line mode）
```text
插入模式 <-> 命令模式 <-> 末行模式
```

- 命令模式（command mode）：
	- 按 `i（insert）/ o（往下空新起一行）/ a（往后移一字符）`：进入 `插入模式`进行字符写入
	- 按 `:`：进入 `末行模式`进行保存或退出
	- 按 `R`：进入替换模式
	- 按 `ctrl + v`：进入注释模式
- 插入模式（insert mode）：
	- 可进行**文字输入**
	- 按 `Esc` 回到命令模式
- 底行模式（last line mode）
	- 保存：`w`
	- 退出：`q`
	- 强制退出：`!q`
	- 设置行号：`set nu`
	- 不退出`vim`使用命令：`! [命令]`
	- 批量化替换：`%s /dst/srt/`
	- `vim 文件名 -> wq （保存文件）`
	- 多文件分屏操作
		- 分屏：`vs 新文件`
		- 切换文件：`ctrl + ww`
	- 搜索单词：`/单词`
	- 报错时，让光标指到对应位置：`vim 文件 + n`
	- 执行上一个底行指令：`!v`
	- 按 `Esc` 回到命令模式
- 替换模式
	- 按 `Esc` 回到命令模式
- 注释模式
	- 批量化注释：
		1. `h j k l`区域选择，可与其他命令结合
		2. `I（大写）` 回到插入模式
		3. 输入 `//`
		4. 按 `Esc`，批量注释成功
	- 区域删除：
		1. `h j k l`区域选择，可与其他命令结合
		2. `d` 删除选择区域
	- 区域编写：
		1. `h j k l`区域选择，可与其他命令结合
		2.  `I（大写）` 回到插入模式
		3. 输入想要加的字符
		4.  按 `Esc`，区域编写成功
	- 按 `Esc` 回到命令模式

# vim 基本操作
## 移动光标（命令模式下）

| 目的     | 指令                          |
| ------ | --------------------------- |
| 左下上右   | `h(左) j(下) k(上) l(右)`       |
| 顶部     | `gg`                        |
| 底部     | `G`                         |
| 指定行    | `[行数] + G`                  |
| 跳跃单个单词 | `w(右) b(左)`                 |
| 跳跃多个单词 | `[跳跃单词数] + w 、[跳跃单词数] + b ` |
| 行首     | `^`                         |
| 行尾     | `$`                         |

| 目的           | 指令                |          |
| ------------ | ----------------- | -------- |
| 复制当 前行/多行    | `yy` / `[数] + yy` |          |
| 光标位置粘贴 一次/多次 | `p` / `[数] + p`   |          |
| 向前撤销         | `u`               |          |
| 向后撤销         | `ctrl + r`        |          |
| 截切 一行/多行     | `dd` / `[数] + dd` |          |
| 右删除字符（可复制）   | `x` / `[数] + x`   |          |
| 左删除字符（可复制）   | `X` / `[数] + X`   |          |
| 替换光标所在字符     | `r` / `[数] + r`   |          |
| 大小写切换        | `~`               |          |
| 选中单词         | `#`               | `n`：逆向查找 |
