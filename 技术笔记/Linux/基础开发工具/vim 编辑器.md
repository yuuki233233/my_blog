# # 代码编辑器 vim
Vim 是 Linux 下的神器，它的核心逻辑是**多模式编辑**。新手只需要掌握三种模式即可：
- **命令模式（Normal）**：默认模式，用于移动光标、复制、删除
- **插入模式（Insert）**：用于打字输入
- **底行模式（Last-line）**：用于保存、退出、替换

>**模式转换规则**：无论你在哪个模式，狂按 `Esc` 键就能回到**命令模式**
>命令模式可以转成其他模式，其他模式只能转回命令模式

## 常用操作

### 1. 进入编辑（命令模式）

- `i`：在光标前插入
- `a`：在光标后插入
- `o`：在光标下一行新建一行插入

### 2. 移动与删除

- `h j k l`：分别对应 左、下、上、右 移动光标
- `gg`：跳到文件首行； `G`：跳到文件尾行
- `dd`：删除（剪切）当前行； `[数字] + dd`：删除多行
- `u`：撤销上一步操作； `Ctrl + r`：反撤销
- `^`：行首；`$`：行尾

### 3. 保存于退出（底行模式）

- 输入 `:` 进入底行模式
- `w`：保存； `q`：退出； `wq`：保存并退出； `q!`：强制退出不保存
- `set nu`：显示行号
- `/单词`：查找单词
- `vs 新文件`、`ctrl + ww`：分屏、切换文件
- `! [命令]`：在 `vim` 中使用命令

| 命令                                 | 模式     |
| ---------------------------------- | ------ |
| `i（insert）/ o（往下空新起一行）/ a（往后移一字符）` | `插入模式` |
| `:`                                | `末行模式` |
| `R`                                | `替换模式` |
| `ctrl + v`                         | `注释模式` |

### 4. 其他操作

| 目的           | 指令                |          |
| ------------ | ----------------- | -------- |
| 复制当 前行/多行    | `yy` / `[数] + yy` |          |
| 光标位置粘贴 一次/多次 | `p` / `[数] + p`   |          |
| 右删除字符（可复制）   | `x` / `[数] + x`   |          |
| 左删除字符（可复制）   | `X` / `[数] + X`   |          |
| 替换光标所在字符     | `r` / `[数] + r`   |          |
| 大小写切换        | `~`               |          |
| 选中单词         | `#`               | `n`：逆向查找 |


### 5. 注释模式

| 步骤  | 批量化注释                  | 区域删除          | 区域编写           |
| --- | ---------------------- | ------------- | -------------- |
| 1   | `h j k l`区域选择，可与其他命令结合 | `h j k l`区域选择 | `h j k l`区域选择  |
| 2   | `I（大写）` 回到插入模式         | `d` 删除选择区域    | `I（大写）` 回到插入模式 |
| 3   | 输入 `//`                |               | 输入想要加的字符       |
| 4   | 按 `Esc`，批量注释成功         |               | 按 `Esc`，区域编写成功 |
按 `Esc` 回到命令模式
