# 操作系统（Operator System）

## 概念

操作系统是一款进行软硬件 **管理** 的软件，操作系统包括：
- 内核：进程管理，内存管理，文件管理，驱动管理
- 其他程序：函数库，shell程序等

## 设计OS的目的

>- 对下，与硬件交互，管理所有的软硬件资源（手段）
>- 对上，为用户程序提供一个良好的执行环境（目的）
>![](图片/操作系统.png)
>1. 软硬件体系结构为层状结构
>2. 访问操作系统，必须使用系统调用（系统提供的函数接口）
>3. 只要程序访问了硬件，必须贯穿整个软硬件体系结构
>4. 库可能在底层封装了系统调用

## 理解 操作系统 “管理”

管理者：操作系统
被管理者：底层硬件
操作系统通过驱动程序，间接管理底层硬件

**管理者如何高效管理底层硬件？**
- 先描述，用 struct 结构体
- 再组织起来，用链表或其他高效的数据结构，将每一个 struct 结构体用指针链接起来

**对硬件：**
操作系统要在自己的内部先描述再组织，把所有的硬件放到一个 struct 结构体定义一个类，类里面定义各种属性（名称、状态等），每一个设备都要对应一个 struct 对象，然后再用链表把对象组织起来，管理硬件转换成对底层硬件的增删查改

**对进程：**
首先操作系统要对进程定义成 struct 结构体，然后再把进程属性放在结构体里，用链接节点把每一个struct 进程链接起来，把对进程的管理转换成对链表的增删查改

**对用户：**
将信息反馈给用户，为用户程序提供一个良好的执行环境
