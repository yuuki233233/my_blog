# 环境变量（程序的隐形配置）

环境变量是 OS 用来指定运行环境的一些参数，通常具有**全局属性**（可以被子进程继承）。
*   **PATH**：指定命令的搜索路径。为什么敲 `ls` 可以直接运行，而你自己写的程序要敲 `./a.out`？因为 `ls` 在 PATH 路径里，而你的不在。
*   **HOME**：当前用户的主工作目录。
*   **SHELL**：当前 Shell 的类型，通常是 `/bin/bash`。
**代码获取**：
可以通过 `main` 函数的第三个参数 `env[]`，或者 `extern char **environ` 全局变量获取。也能用 `getenv("PATH")` 函数直接拿到特定变量的值。
