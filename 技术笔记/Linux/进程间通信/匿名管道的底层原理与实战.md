# 匿名管道

## 为什么父子进程能通过管道通信

单独一个进程调用 `pipe()` 只能自己写自己读。要通信，必须配合 `fork()`
1. 父进程创建管道，得到 `f[0]` 和 `f[1]`
2. 父进程 `fork()` 出子进程。因为子进程会拷贝父进程的文件描述符表，所以子进程也拥有 `f[0]` 和 `f[1]`，并且**指向内核的同一个管道**
3. 为了实现单向通信，父进程关闭 `f[0]`（读），子进程关闭 `f[1]`（写）
4. 于是，父进程写，子进程读。管道一下就通了
