目录：inode + 数据内容 + 目录名(同存储在上级的数据内容中)
文件：inode + 文件名
>文件名保存在目录的`数据内容里`
>查找文件 inode 的方式：路径(目录)中打开数据内容，通过文件名找到 inode  `此时文件名与 inode 产生映射关系`

目录的上级目录：inode + 数据内容 + 名
目录：inode + 数据内容 + 名
>目录名存在上级目录的`数据内容里`
>查找目录 inode 的方式：通过映射在上级目录中的`数据内容`找到目录的 inode


> [!NOTE] 递归查找
> 反向推导：文件 -> 目录 -> 上级目录 -> ... -> root
> 系统查找方式：root -> ... -> 上级目录 -> 目录 -> 文件


目录、文件关系：
- 目录和文件都以 `inode + 属性` 存储在磁盘中，但目录里的内容保存了文件(文件名 + 其他属性)
- 文件名不存储于属性中

默认路径：
- 系统会将 ls 解析成默认路径，默认路径由进程提供(可以理解成虚拟环境env)

路径缓存：
- 每查找一次文件从 root 解析的效率低，Linux会在内存中以多叉树的形式缓存

磁盘挂载：
- 并不能通过 inode 知道磁盘分区，但操作系统通过磁盘挂载在目录中，将新文件创建在对应的挂载到磁盘分区中的目录
