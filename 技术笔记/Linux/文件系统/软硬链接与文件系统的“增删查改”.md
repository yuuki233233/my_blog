# 软链接与硬链接

我们平时用 `ln` 命令可以创建链接。分为硬链接和软连接，它们在 inode 层面的表现完全不同

## 1. 硬链接（Hard Link）

`ln abc def`
- **原理**：并没有新建 inode，而是让 `def`  这个名字 -> `abc` 的inode。在目录的数据块中，新增了一行 `def` <-> inode编号
- **特征**：inode 的 `i_link_count`（硬链接数）会 +1。当你删除 `abc` 时，只是把 `links_count` -1。只有减到 0 时，数据块才会真正被释放
- **限制**：不能跨分区（inode 也不能跨分区）。不能对目录创建硬链接（防止死循环）

## 2. 软连接（Soft Link）

`ln -s abc def`
- **原理**：新建了一个全新的文件 `def`（有自己的 inode 和数据块）。只不过 `def` 的数据块里存的内容，是 `abc` 的路径字符串
-  **特征**：类似 Windows 的快捷方式。如果你删除了 `abc`，`def` 还在，但它会变成死链接（找不到目标）
