# 一、列表初始化
## 1.1 {}
- `C++11`实现一切对象皆可用`{}`初始化，`{}`初始化叫做列表初始化。注意：与构造中的初始化列表做区分
- 列表初始化的初衷是为了统一初始化方式
**接下来列举C++98和C++11的个别样例：**
```cpp
struct Point
{
	int _x;
	int _y;
};

class Date
{
public:
	Date(int year = 1, int month = 1, int day = 1)
		:_year(year)
		,_month(month)
		,_day(day)
	{
		cout << "Date() -> 直接构造" << endl;
	}
	
	Date(const Date& d)
		:_year(d.year)
		,_month(d.month)
		,_day(d.day)
	{
		cout << "Date(const Date& d) -> 拷贝构造" << endl;
	}
	
private:
	int _year;
	int _month;
	int _day;
}

int main()
{
	/* C++98 */
	int a1[] = { 1,2,3 };
	int a2[5] = { 0 };
	Point p = { 1, 2 }; // 结构体
	Date d = 2026;

	/* C++11 */
	
	int x1 = { 2 }; // 内置类型
	
	/*
	直接构造{ 2025, 1, 1 } -> 临时变量
	临时变量去拷贝构造 -> d1
	编译器优化: 直接构造
	*/
	Date d1 = { 2025, 1, 1 };
	Date d2 = { 2025 }
	const Date& d3 = {2025, 1, 1}; // {Date}具有常性
	
	/* 使用{}, 可以省略= */
	Point p1 { 1, 2 };
	int x2 { 2 };
	Date d3 { 2025, 1, 1 };
	const Date& d4 = { 2025 };
	
	/* 数据的插入方式 */
	// 1. 有名对象
	// 2. 匿名对象
	// 3. {}
	vector<Date> v;
	v.push_back(d1);
	v.push_back(Date(2025, 1, 1));
	v.push_back({2025, 1, 1});
	
	return 0;
}
```

- initializer : 如`initializer_list<int> li = {1, 2, 3}`, 本质是底层开一个数组, 将数组拷贝过来, 迭代器分别指向头和尾, 一次性完成

# 二、& 和 &&
##  2.1 左值（lvalue）和右值（rvalue）
**左值（lvalue）：** 
- 数据的表达式（如变量名，解引用的指针）
- 一般是持久的（通常是自己定义的），存储在内存中，可以取地址
- 左值可以修改，但 const 修饰的左值不能修改，可以取地址
**右值（rvalue）：** 
- 数据的表达式
- 大多都常量或临时变量，不能取地址
- 右值只能出现在赋值符号的右边，不能取地址
```cpp

// 左值：可以取地址
	int* p = new int(0);
	int b = 1;
	const int c = b;
	string s("11111111");
	/* operator，因为是字符类型，需强转成 void*取地址 */
	s[0] = 'x';

	cout << &c << endl;
	cout << (void*)&s[0] << endl;

// 右值不能取地址
	10;
	b + b;
	/* 返回值 -> 临时变量 */
	fmin(b, b);
	string("11111111");
```
## 2.2 左值引用（lvalue reference）和右值引用（rvalue reference）
- 左值引用是给左值取别名，右值引用是给右值取别名
- 左值引用不能直接引用右值，但 **const左值引用（具有常性）** 可以引用**右值（常性）**
- 右值引用不能直接引用左值，但 **move(左值)** 可以被右值引用 
- move 是个函数模板，本质内部进行强制类型转换
- 变量表达式都是左值属性（右值被右值引用绑定后，其右值的属性是左值）
```cpp
// 左值：可以取地址
int b = 1;
int* p = new int(0);
const int c = b;
string s("11111111");
s[0] = 'x';
double x = 1.1, y = 2.2;

// 左值引用给左值取别名
int& r1 = b;
int*& r2 = p;
const int& r3 = c;
string& r4 = s;
char& r5 = s[0];

// 右值引用给右值取别名
int&& rr1 = 10;
double&& rr2 = x + y;
double&& rr3 = fmin(x, y);
string&& rr4 = string("11111111");

// 左值引用不能直接引用右值，但const左值可以引用右值
const int& rx1 = 10;
const double& rx2 = x + y;
const double& rx3 = fmin(x, y);
const string& rx4 = string("11111111");

// 右值引用不能直接引用左值，但可以引用move(左值)
int&& rrx1 = move(b);
int*&& rrx2 = move(p);
int&& rrx3 = move(*p);
const int&& rrx4 = move(c);
string&& rrx5 = move(s);
char&& rrx6 = move(s[0]);


// b, r1, rr1都是变量表达式，都是左值
cout << &b << endl;
cout << &r1 << endl;
cout << &rr1 << endl;

// int&& rr1 = 10;
/* 右值引用本身的属性会被变成左值 */
// 注意：rr1的属性是左值，所以不能再被右值引用绑定，除非move一下
int& r6 = rr1;
//int&& rrx7 = rr1;
int&& rrx7 = move(rr1);
```

## 2.4 左值和右值的参数匹配
- `C++98`中，`const左值引用`作为参数的函数，实参传替左值和右值的可以
- `C++11`后，分别重载`左值引用、const左值引用、右值引用`作为形参的函数，那么实参是左值会匹配左值引用，实参是`const左值`会匹配`const左值引用`，实参是右值会匹配右值引用
- 右值引用变量在用于表达式时表现出左值的属性
 ```cpp
 void f(int& x)
{
	cout << "左值引用重载" << endl;
}

void f(const int& x)
{
	cout << "const左值引用重载" << endl;
}

void f(int&& x)
{
	cout << "右值引用重载" << endl;
}

void test06()
{
	int i1 = 1;
	const int i2 = 2;

	f(i1);			// 左值引用重载
	f(i2);			// const左值引用重载
	f(3);			// 右值引用重载
	f(move(i1));	// 右值引用重载

	// 右值引用变量在于表达式时是左值
	int&& x = 1;
	f(x);			// 左值引用重载
	f(move(x));		// 右值引用重载
}
 ```
## 2.5 右值引用和移动
### 2.5.1 左值引用的使用场景
1. 函数中左值引用传参
2. 左值引用传返回值减少拷贝
3. 修改实参和修改返回对象
有些场景不能使用左值引用返回，如`addStrings`和`generate`函数，因为本质时返回局部对象，函数结束对象就析构销毁
## 2.5.2 移动构造和移动赋值
- 移动构造类似于拷贝构造函数，不同的是这个参数是右值引用
- 移动赋值类似于赋值运算符重载，不同的是这个参数是右值引用
- 对于自定义类型如`string,vector`这样深拷贝的成员变量，移动构造和移动赋值才有意义。因为移动构造和移动赋值的第一个参数是右值引用类型，本质是窃取资源，提高效率
```cpp
#pragma once
#include<iostream>
#include<assert.h>
using namespace std;
 
namespace yuuki
{
	class string
	{
	public:
		//用迭代器时
		typedef char* iterator;
		typedef const char* const_iterator;

		string(const char* str = " ")
		{
			_size = strlen(str);
			_capacity = _size;
			_str = new char[_capacity + 1];
			strcpy(_str, str);

			cout << " string() -- 构造" << endl;
		}

		//s2(s1)
		string(const string& str)
		{
			_str = new char[str._capacity + 1];
			strcpy(_str, str._str);
			_size = str._size;
			_capacity = str._capacity;

			cout << " string(const string & str) -- 拷贝构造" << endl;
		}

		//s2 = s1
		string& operator=(const string& str)
		{
			// s1 = s1(深拷贝)
			if (this != &str)
			{
				delete[] _str;
				_str = new char[str._capacity + 1];
				strcpy(_str, str._str);
				_size = str._size;
				_capacity = str._capacity;
			}
			cout << " string& operator=(const string& str) -- 赋值重载" << endl;

			return *this;
		}

		~string()
		{
			delete[] _str;
			_str == nullptr;
			_size = _capacity = 0;
		}

	private:
		char* _str;
		int _size;
		int _capacity;

		static const size_t npos;
	};
}

#include"string.h"
#include<assert.h>

int main()
{
	yuuki::string s1("111111111111111");
	yuuki::string s2("111111111111111");

	yuuki::string s3(s1);
	yuuki::string s4 = yuuki::string("22222222222");
	yuuki::string s5 = move(s1);

	return 0;
}
```
## 右值引用和移动语义解决传值返回问题
```cpp
namespace yuuki
{
	string addStrings(string num1, string num2)
	{
		string str;
		int end1 = num1.size() - 1, end2 = num2.size() - 1;
		int next = 0;
		while (end1 >= 0 || end2 >= 0)
		{
			int val1 = end1 >= 0 ? num1[end1--] - '0' : 0;
			int val2 = end2 >= 0 ? num2[end2--] - '0' : 0;
			
			int ret = val1 + val2 + next;
			next = ret / 10;
			ret = ret % 10;
			
			str += ('0' + ret);
		}
		
		if (next == 1)
			str += '1';
			
		reverse(str.begin(), str.end());
		
		cout << "******************************" << endl;
		
		return str;
	}
}

// 场景1
```
