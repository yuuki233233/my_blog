# 列表初始化
## {}
- `C++11`实现一切对象皆可用`{}`初始化，`{}`初始化叫做列表初始化。注意：与构造中的初始化列表做区分
- 列表初始化的初衷是为了统一初始化方式
**接下来列举C++98和C++11的个别样例：**
```cpp
struct Point
{
	int _x;
	int _y;
};

class Date
{
public:
	Date(int year = 1, int month = 1, int day = 1)
		:_year(year)
		,_month(month)
		,_day(day)
	{
		cout << "Date() -> 直接构造" << endl;
	}
	
	Date(const Date& d)
		:_year(d.year)
		,_month(d.month)
		,_day(d.day)
	{
		cout << "Date(const Date& d) -> 拷贝构造" << endl;
	}
	
private:
	int _year;
	int _month;
	int _day;
}

int main()
{
	/* C++98 */
	int a1[] = { 1,2,3 };
	int a2[5] = { 0 };
	Point p = { 1, 2 }; // 结构体
	Date d = 2026;

	/* C++11 */
	
	int x1 = { 2 }; // 内置类型
	
	/*
	直接构造{ 2025, 1, 1 } -> 临时变量
	临时变量去拷贝构造 -> d1
	编译器优化: 直接构造
	*/
	Date d1 = { 2025, 1, 1 };
	Date d2 = { 2025 }
	const Date& d3 = {2025, 1, 1}; // {Date}具有常性
	
	/* 使用{}, 可以省略= */
	Point p1 { 1, 2 };
	int x2 { 2 };
	Date d3 { 2025, 1, 1 };
	const Date& d4 = { 2025 };
	
	/* 数据的插入方式 */
	// 1. 有名对象
	// 2. 匿名对象
	// 3. {}
	vector<Date> v;
	v.push_back(d1);
	v.push_back(Date(2025, 1, 1));
	v.push_back({2025, 1, 1});
	
	return 0;
}
```
## initializer_list
- 传统方式 : 如`vector<int> v1 = {1, 2, 3}`, 需进行多次构造函数实现
- initializer : 如`initializer_list<int> li = {1, 2, 3}`, 本质是底层开一个数组, 将数组拷贝过来, 迭代器分别指向头和尾, 一次性完成
```cpp
// 构造+拷贝构造+优化
vector<int> v1 = {1, 2, 3};
vector<int> v2 = {10, 20, 30};

// 构造
vector<int> v3({10, 20, 30});
vonst vector<int>& v4({10, 20, 30});

// C++11
```
