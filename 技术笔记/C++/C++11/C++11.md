# 列表初始化
## {}
- `C++11`实现一切对象皆可用`{}`初始化，`{}`初始化叫做列表初始化。注意：与构造中的初始化列表做区分
- 列表初始化的初衷是为了统一初始化方式
**接下来列举C++98和C++11的个别样例：**
```cpp
struct Point
{
	int _x;
	int _y;
};

class Date
{
public:
	Date(int year = 1, int month = 1, int day = 1)
		:_year(year)
		,_month(month)
		,_day(day)
	{
		cout << "Date() -> 直接构造" << endl;
	}
	
	Date(const Date& d)
		:_year(d.year)
		,_month(d.month)
		,_day(d.day)
	{
		cout << "Date(const Date& d) -> 拷贝构造" << endl;
	}
	
private:
	int _year;
	int _month;
	int _day;
}

int main()
{
	/* C++98 */
	int a1[] = { 1,2,3 };
	int a2[5] = { 0 };
	Point p = { 1, 2 }; // 结构体
	Date d = 2026;

	/* C++11 */
	
	int i = { 2 }; // 内置类型
	
	/*
	{ 2025, 1, 1 } -> 临时变量
	临时变量
	*/
	Date d1 = { 2025, 1, 1 };
	
	return 0;
}
```
