# 只能指针的使用及原理
## 智能指针使用场景分析
>问题引入：
>case 1：**无异常**
>- `try` 中创建 `array1、array2`，`array1，array2` 都创建成功，没抛出异常，`array` 正常销毁。**（无内存泄漏）**
>case 2：**有异常**
>- `try` 中创建 `array1、array2`，`array1` 先发生异常，因创建失败而没申请空间，因先跳转到 `catch` 没创建 `array2`。**（无内存泄漏）**
>- `try` 中创建 `array1、array2`，`array2` 发生异常，此时 `array1` 申请了空间，因 array2 发生异常被 catch 捕捉，array1 因跳到 catch 而没有被释放。**（内存泄漏）**
>因为 case 2 中可能会因异常而导致内存泄漏，需要我们手动在外层 catch 再写一遍，就此产生了智能指针帮我们管理内存。
