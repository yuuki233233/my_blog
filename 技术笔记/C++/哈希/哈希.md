# 一、哈希概念
**哈希(hash)又称散列**，是一种组织数据的方式。通过**哈希函数把关键字Key跟存储位置建立一个映射关系**，查找是通过这个哈希函数计算出key存储位置，进行快速查找。
## 1.1 直接定址法
主要用于：关键字的范围比较集中。比如一组关键字在`[0,99]`之间，那么就开100个数的数组，每个关键值就是数组的下标。比如一组关键字值都在`[a,z]`的字母之间，那么我们开26个数的数组，每个关键字acsii码值就是存储位置的下标
## 1.2 哈希冲突
当关键字的范围比较分散时，用直接定址法就浪费内存，可能内存不够用。比如有`[0,9999]`数据范围的 N 个值，映射到一个 M 个空间的数组中（一般情况下 M >= N），那么我们就要借助哈希函数，关键字`key`被映射到对应数组的位置，要注意对需映射值计算出的值必须在`[0,M)`之间。
两个不同的`key`可能映射到同一个位置，就产生了哈希冲突
## 1.3 负载因子
哈希表：大小->M，存储->N。负载因子：`N/M`
- 负载因子越大，哈希冲突的概率越高，空间利用率越高
- 相反负载因子越小，哈希冲突的概率越低，空间利用率越低
当**负载因子 >= 0.7**时就可以考虑给哈希表扩容
## 1.4 将关键字转为整数
我们将关键字映射到数组中的位置，一般时整数。如果是字符串，就将每个字母的ASCII码值相加，再放到对应数组的位置
## 1.5 哈希函数
可以让N个关键字被等概率散列分布到哈希表的M个空间中
### 1.5.1 除法散列法/除留余数法
- 假设哈希表大小为 `M`。映射位置的下标：`h(key) = key % M`
- 使用除法散列表，最好使用素数作为数组空间大小，尽量避免为2的次方和10的次方
- 数组大小为素数，是为了让更多的位置参与运算，映射出来的值产生的冲突概率越小
## 1.6 处理哈希冲突
实践中，一般选择除法散列表作为哈希函数。当发生冲突时可以选择**开发定址法和链地址法**
### 1.6.1 开发定址法
在开放定址法中所有的元素都放到哈希表里，当一个关键字key用哈希函数计算出的位置冲突了，则按照某种规则找到一个没有存储数据的位置进行存储，开放定址法中负载因子一定是小于的。这里的规则有三种：线性探测、二次探测、双重探测。
#### 线性探测
- 从发生冲突的位置开始，依次线性向后探测，直到寻找到下一个没有存储数据的位置为止，如果走到哈希表尾，则回绕到哈希表头的位置。
- `hash0 = key % M`，hash0位置冲突了，则线性探测公式为:`hashi = (hash0+i) % M`，因为负载因子小于1,则最多探测M-1次，一定能找到一个存储key的位置。
- 线性探测的比较简单且容易实现，线性探测的问题假设，hasho位置连续冲突，hasho，hash1，hash2位置已经存储数据了，后续映射到hash0，hash1，hash2，hash3的值都会争夺hash3位置，这种现象叫做群集/堆积。下面的二次探测可以一定程度改善这个问题。
#### 二次探测
- 从发生冲突的位置开始，依次左右按二次方跳跃式探测，直到寻找到下一个没有存储数据的位置为止，如果往右走到哈希表尾，则回绕到哈希表头的位置；如果往左走到哈希表头，则回绕到哈希表尾的位置；
- `hash0 = key % M`，hash0位置冲突了，则二次探测的公式为：`hashi = (hash0 + i*i) % M`
- 二次探测，当`hashi = (hash0 - i*i) % M`时，`hashi < 0时，需要hahsi += M`
### 1.6.2 开发定址法代码实现
初始数组大小(N)应为素数，是为了让更多的位置参与运算，映射出来的值产生的冲突概率越小
存储位置：数据大小(key) % 数组大小(N)
1. 若存在冲突，用线性探测
	1. 找需插入的位置
	2. 如位置被占，需线性探测(如越界，需取模)
	3. 找到空位置/删除位置，放入位置，状态设为存在
	4. 节点个数++
2. 若冲突因子>=0.7，则扩容 (创建新数组，将旧数组的数据插入到新数组，然后交换数组)
```cpp
#pragma once
#include<iostream>
using namespace std;
#include<vector>

enum State
{
	EXIST,
	EMPTY,
	DELETE
};

template<class K, class V>
struct HashDate
{
	pair<K, V> _kv;
	State _state = EMPTY;
};

template<class K, class V>
class HashTable
{
public:
	HashTable()
		:_tables(11)
		,_n(0)
	{ }

	bool Insert(const pair<K, V>& kv)
	{
		// 不允许冗余
		if (Find(kv.first))
			return false;

		// 负载因子 >= 0.7 扩容
		if (_n * 1.0 / _tables.size() >= 0.7)
		{
			// 创建个哈希表
			HashTable<K, V> NewHash;
			// 用reserve扩容到两倍
			NewHash._tables.reserve(_tables.size() * 2);
			for (auto& data : _tables) // 插入旧表中存在的值
			{
				if (data._state == EXIST)
				{
					NewHash.Insert(data._kv);
				}
			}
			// 新旧表交换数据
			_tables.swap(NewHash._tables);
		}

		// 找需插入的位置
		size_t Hash0 = kv.first % _tables.size();
		size_t Hashi = Hash0; // 记录插入位置
		int i = 1; // 线性探测需++

		// 找空位置
		while (_tables[Hashi]._state == EXIST)
		{
			Hashi = (Hash0 + i) % _tables.size();
			++i;
		}

		// 找到了插入到空位置
		_tables[Hashi]._kv = kv;
		_tables[Hashi]._state = EXIST;
		++_n;

		return true;
	}
private:
	vector<HashDate<K, V>> _tables;
	size_t _n; // 记录数据个数
};
```
