# 一、二叉搜索树的概念
二叉搜索树又称二叉排序树
- 左子树不为空，则左子树上所有节点的值都小于等于根节点的值
- 右子树不为空，则右子树上所有节点的值都大于等于根节点的值
- 左右子树也分别为二叉搜索树
- 二叉搜索树中可以支持插入相同的值，也可以不支持插入相等的值。其中`map、set、multimap、multiset`系列的如期底层就是二叉搜索树，其中`map、set`不支持插入相等值，`multimap、multiset`支持插入相等的值。

# 三、二叉搜索树的整体框架
## 3.1 节点
二叉搜索树本质就是链表，用多个单独的节点连接而成
```cpp
#pragma once
#include<iostream>
using namespace std;

// 结构
template<class K>
struct BSTNode
{
	K _key; // 接收值
	BSTNode<K>* _left;	// 左孩子节点
	BSTNode<K>* _right; // 右孩子节点
	BSTNode(const K& key) // 默认构造
		:_key(key)
		,_left(nullptr)
		,_right(nullptr)
	{}
};
```
## 3.2 树的创建
节点和树都是单独的类，当节点用在树的类中，因为命名太长需要用到宏修改一下命名，C++11中也有新的用法：`using Node = BSTNode<K>`
```cpp
template<class K>
class BSTree
{
	//typedef BSTNode<K> Node;	// 普通写法
	using Node = BSTNode<K>;	// C++11写法
public:
private:
	Node* _root = nullptr; // 根节点的指针
};
```
## 3.3 插入
插入的具体过程：
1. 树为空，则直接新增节点，赋值给root指针
2. 树不为空，按二叉搜索树性质，插入值比当前节点大往右走，比当前节点小往左走，找到空位置，插入新节点
3. 如果支持插入相等值，插入值跟当前节点相等的值可以往右走或往左走(要保持逻辑一致性)
![](图片/二叉搜索树的插入01.png)
```cpp
int a[] = {8, 3, 1, 10, 6, 4, 7, 14, 13};
```
![](图片/二叉搜索树的插入02.png)![](图片/二叉搜索树的插入03.png)
```cpp
bool Insert(const K& key)
{
	// 情况一：树为空
	if (_root == nullptr)
	{
		_root = new Node(key);
		return true;
	}

	// 情况二：树不为空
	Node* cur = _root;
	Node* parent = nullptr;
	while (cur) // 遍历树(找到空就放入)
	{
		if (cur->_key < key)
		{
			parent = cur;
			cur = cur->_right;
		}
		else if (cur->_key > key)
		{
			parent = cur;
			cur = cur->_left;
		}
		else
		{
			return false; // 若相等，不插入
		}
	}

	cur = new Node(key); // 创建节点，未连接
	if (parent->_key < key) // 大的连接右边
	{
		parent->_right = cur;
	}
	else
	{
		parent->_left = cur;
	}
	return true;
}
```
## 3.4 查找
1. 从根开始比较，查找`x`，`x`比根的值大则往右边查找，小则往左边查找
2. 最多查找高度次，走到空则没有这个值
3. 如果不支持插入相等的值，找到`x`即可返回
4. 如果支持插入相等的值，意味着有多给`x`存在，一般要求查找中序的第一个`x`。如下图，查找3，要找到1的右孩子的3返回![](图片/二叉搜索树的查找.png)
```cpp
// 查找
bool Find(const K& key)
{
	Node* cur = _root;
	while (cur)
	{
		if (cur->_key < key)
		{
			cur = cur->_right;
		}
		else if (cur->_key > key)
		{
			cur = cur->_left;
		}
		else
		{
			return true;
		}
	}
}
```
## 3.5 删除
首先查找元素是否在二叉搜索树中，如果不存在，则返回`false`
如果删除的元素存在，则分以下四种情况处理：
1. 左右孩子为空
2. 左孩子为空
3. 右孩子为空
4. 左右孩子都不为空

应对以上的四种情况的解决方式：
1. 把节点的父亲对应的孩子指针指向空，直接删除节点(情况1可以当成情况2、3处理)
2. 把节点的父亲对应孩子指针指向右孩子，直接删除节点
3. 把节点的父亲对应孩子指针指向左孩子，直接删除节点
4. 无法直接删除节点，因为两孩子无处安放，只能用替换法删除。找左子树的值最大节点或者右子树的值最小节点替代删除的节点，因为这两个节点中任意一个，放到要删除的为止，都满足二叉搜索树的规则。替代节点的意思就是，把需删除的和找到最小/最大的两个节点交换，转而变成删除
