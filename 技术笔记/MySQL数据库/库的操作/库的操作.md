# 库的操作

## 创建数据库

```mysql
CREATE DATABASE [IF NOT EXISTS] db_name [create_specification [,
create_specification] ...]

create_specification:
[DEFAULT] CHARACTER SET charset_name
[DEFAULT] COLLATE collation_name
```
说明：
- 大写的表示关键字
- [] 是可选项
- CHARACTER SET：指定数据库采用的字符集
- COLLATE：指定数据库字符集的校验规则


## 创建数据库案例

- 创建数据库
```mysql
create database [you_file];
```
>说明：当我们创建数据库没有指定字符集和校验规则时，系统使用默认的字符集：utf8，校验规则是：utf8_general_ci

- 创建一个使用 utf8 字符集的数据库
```mysql
create database [you_file] charset=utf8;
```

- 创建一个使用 utf 字符集，并带校对规则的数据库
```mysql
create database [you_file] collate utf8_general_ci;
```

## 字符集和校验规则

创建数据库是，有两个编码集：
1. 数据库编码集
2. 数据库校验集
必须统一每一个数据库的表中的编码集和校验集

### 查看系统默认字符集及校验规则

```mysql
show variables like 'character_set_database';
show variables like 'collation_database';
```

### 查看数据库支持的字符集

```mysql
show charset;
```
字符集主要是控制用什么语言。比如 utf8 就可以使用中文

### 查看数据库支持的字符集校验规则

```mysql
show collation;
```

## 验证不同校验编码的影响

### 校验规则对数据库的影响

#### 不区分大小写

- 创建一个数据库，校验规则使用 utf8_general_ci
```mysql
create database test1 collate uft8_general_ci;
```
```mysql
use test1;
```
```mysql
create table MyFile(name varchar(20));
```
```mysql
insert into MyFile values('a');
insert into MyFile values('A');
insert into MyFile values('b');
insert into MyFile values('B');
```

- 查询结果
```mysql
mysql> use test1;
mysql> select * from person where name='a';
+------+
| name |
+------+
| a |
| A |
+------+
2 rows in set (0.01 sec)
```

- 排序结果
```mysql
mysql> use test1;
mysql> select * from person order by name;
+------+
| name |
+------+
| a |
| A |
| b |
| B |
+------+
```

#### 区分大小写

- 创建一个数据库，校验规则使用 utf8_bin
```mysql
create database test1 collate uft8_bin;
```
```mysql
use test2;
```
```mysql
create table MyFile(name varchar(20));
```
```mysql
insert into MyFile values('a');
insert into MyFile values('A');
insert into MyFile values('b');
insert into MyFile values('B');
```

- 查询结果
```mysql
mysql> use test2;
mysql> select * from person where name='a';
+------+
| name |
+------+
| a |
+------+
2 rows in set (0.01 sec)
```

- 排序结果
```mysql
mysql> use test2;
mysql> select * from person order by name;
+------+
| name |
+------+
| A |
| B |
| a |
| b |
+------+
```

## 数据库的查删改

### 查看数据库

```mysql
show databases;
```

### 显示创建语句

```mysql
show create databases [you_file];
```

示例：
```mysql
mysql> show create database mytest;
+----------+----------------------------------------------------------------+
| Database | Create Database |
+----------+----------------------------------------------------------------+
| mysql | CREATE DATABASE `mytest` /*!40100 DEFAULT CHARACTER SET utf8 */ |
+----------+----------------------------------------------------------------+
```
说明：
- MySQL 建议我们关键字使用大写，但不是必须的
- 数据库名字的反引号` `` `，是为了防止使用的数据库名与关键字相同
- `/*!40100 DEFAULT CHARACTER SET utf8 */`不是注释，表示当前 mysql 版本大于 4.01 版本，就执行这句话

### 修改数据库

- 对数据库的修改，主要是修改数据库的字符集，校验规则
- 下面将数据库字符集改成 `gbk`
```mysql
alter database [you_file] charset=gbk;
```

### 删除数据库

```mysql
drop database [you_file];
```
```mysql
drop database if exists [you_file];
```
执行删除后的结果：
- 数据库内部看不到对应的数据库
- 对应的数据库文件夹被删除，里面的数据表全部被删

## 备份和恢复

### 备份

```mysql
mysqldump -P3306 -u root -p 密码 -B 数据库名 > 数据库备份存储的文件路径
```
- `-B`：除了将数据库内容拷贝过去，使用的命令也一同拷贝过去
- 数据库备份存储的文件路径：拷贝在我的 `Linux` 的路径下

### 还原

```mysql
source  数据库备份存储的文件路径
```

### 注意事项

- 备份表
```mysql
mysqldump -u root -p 数据库名 表1 表2 ... > 数据库备份存储的文件路径
```
- 备份多个数据库
```mysql
mysqldump -u root -p -B 数据库1 数据库2 ... > 数据库备份存储的文件路径
```
注意：如果备份没有带 `-B` 参数，在恢复时需要创建空数据库，然后使用数据库，在使用 source 来还原（不推荐不加参数）

### 查看连接情况

```mysql
show processlist;
```
如果查出某个用户不是你正常登录的，很有可能你的数据库被人入侵了
