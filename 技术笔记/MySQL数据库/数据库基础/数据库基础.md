# 数据库基础

## 一、什么是数据库

### 1.1 用户端 与 服务端

1. mysql：数据库服务的**客户端**
2. mysqld：数据库服务的**服务器端**
3. mysql 本质：基于 C(mysql) S(mysqld)  模式的一种**网络服务**

- mysql 是一套给我们提供数据存取的服务的网络程序
- 数据库一般指的是，在磁盘或者内存种存储的特定结构组织的数据 -- 将来在磁盘上存储的一套数据库方案
- 数据库服务 -- mysqld

### 1.2 数据库是特殊的文件

文件保存数据有以下几个缺点：
- 文件的安全性问题（需要给文件加权限）
- 文件不利于数据查询和管理，不利于存储海量数据
- 文件在程序中控制不方便
>一般的文件确实提供了数据的存储功能，但是文件并没有提供非常好的数据(内容)管理能力(用户角度)

数据库存储介质：
- 磁盘
- 内存
>数据库本质：对数据内容存储的一套解决方案，你(mysql)给我(mysqld)字段或者要求，我(mysqld)直接给你(mysql)结果就行

**总结**
>服务器最终会收到客户端（mysql）下达的指令，然后被服务器中的 mysqld 识别到，它会在磁盘上建立目录

## 二、基本使用

### 2.1 连接服务器

```bash
mysql -h 127.0.0.1 -P 3306 -u root -p
```
- `-h`：指明登录部署了 mysql 服务器的主机
- `-P`：指明我们要访问的端口号
- `-u`：指明登录用户
- `-p`：指明需要输入密码

>注意：
>如果没有写 `-h 127.0.0.1` 默认是连接本地
>如果没有写 `-p 3306` 默认是连接 `3306` 端口号

### 2.2 服务器，数据库，表关系

- 所谓安装数据库服务器，只是在机器上安装了一个数据库管理系统程序，这个管理程序可以管理多个数据库，一般开发人员会针对每一个应用创建一个数据库
- 为保存应用中实体的数据，一般会在数据库中创建多个表，以保存程序中实体的数据

### 2.4 使用案例

#### 2.4.1 创建数据库

- 创建数据库（文件）
```mysql
create database helloworld;
```

我们去创建一个 helloworld 的文件，看看数据库内会发生什么？
```bash
mysql> create database helloworld;
Query OK, 1 row affected (0.00 sec)

mysql> show databases;
+--------------------+
| Database           |
+--------------------+
| information_schema |
| helloworld         |
| mysql              |
| performance_schema |
| sys                |
+--------------------+
5 rows in set (0.00 sec)
```
观察到表中多了一个 helloworld 文件

在 MySQL 中创建了 helloworld 文件，在 mysqld 中的数据目录中，也存在一份 helloworld 文件
```bash
[root@izj6cd3zr5adf6jnm3mwihz ~]# ls /var/lib/mysql

client-cert.pem  ibdata1         mysql        private_key.pem     sys
```

>建立数据库，本质就是 Linux 下的一个目录

#### 2.4.2 使用数据库

- 使用数据库（目录）
```mysql
use helloworld;
```

#### 2.4.3 创建数据库表

- 创建数据库表（文件）
```mysql
create table [创建的表](
	-> ...,
	-> ...
	);
```

```mysql
mysql> create table student(
    -> name varchar(32),
    -> age int,
    -> gender varchar(2)
    -> );
```

- 查看 helloworld 数据库中的信息
```bash
ls /var/lib/mysql/[创建的数据库]
```

>在数据库内建表，本质就是在 Linux 下创建对应的文件

#### 2.4.4 表中插入数据

- 往表中插入数据
```mysql

```


## 三、SQL 分类

- `DDL【data definition language】`数据定义语言，用来维护存储数据的结果
	代表命令：`create，drop，alter`
- `DML【data manipulation language】`数据操作语言，用来对数据进行操作
	代表指令：`insert，delete，update`
	- DML中又单独分了一个DQL，数据查询语言，代表指令：`select`
- DCL`【data Control language】`数据控制语言，主要负责权限管理和事务
	代表指令：`grant，revoke，commit`
