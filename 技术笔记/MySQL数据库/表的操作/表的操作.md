# 表的操作

## 创建表

```mysql
create table table_name(
	field1 datatype,
	field2 datatype,
	field3 datatype
	)charset=字符集 collate=校验规则 engine=存储引擎;
```
说明：
- `field`：列名
- `datatype`：列的类型
- `character`：字符集，如果没有写，以所在数据库的字符集为准
- `collate`：校验规则，如果没有写，以所在数据库的校验规则为准

## 创建表的案例

```mysql
create table users(
	id int,
	name varchar(20) comment '用户名',
	password char(32) comment '密码',
	birthday date comment '生日'
)charset=utf8 collate=utf8_general_ci engine=MyISAM;
```
说明：
- 不同的存储引擎，创建表的文件不一样
- `users` 表存储引擎时 `MyISAM`，在数据目中有三个不同的文件，分别是
	- `users.frm`：表结构
	- `users.MYD`：表数据
	- `users.MYI`：表索引

## 修改表

在项目实际开发中，经常修改某个表的结构，比如字段名字，字段大小，字段类型，表的字符集类型，
表的存储引擎等等。我们还有需求，添加字段，删除字段等等。这时我们就需要修改表
```mysql
ALTER TABLE tablename ADD (column datatype [DEFAULT expr][,columndatatype]...);

ALTER TABLE tablename MODIfy (column datatype [DEFAULT expr][,columndatatype]...);

ALTER TABLE tablename DROP (column);
```

### 添加数据与列表

- 在 users 表添加记录
```mysql
insert into users values(1, 'a', 'b', '2007-06-18');
```

- 在 users 表添加一个字段
```mysql
alter table users add assets varchar(100) comment '路径' after birthday;
```
说明：
- `assets varchar(100)`：添加的字段
- `comment '路径'`：提交说明
- `after birthday;`：添加到哪一列后面
插入新字段后，对原来的表中的数据没有影响

### 修改列表长度

```mysql
alter table users modify name varchar(60) comment '****';
```
说明：
- 修改列表长度：本质是将数据覆盖，一定要写完整

### 删除列表

```mysql
alter table users rename to employee;
```
说明：
- `rename to`：修改命令，左（`users`）为旧表，右（`employee`）为新表
- 可以省略 `to`

### 修改列表名

```mysql
alter table employee change name xingming varchar(60);
```
说明：
- `change`：命令（左 `employee` 为旧表名，右 `name xingming varchar(60)` 为新表明）
- 新字段一定要完整

## 删除表

```mysql
DROP [TEMPORARY] TABLE [IF EXISTS] tbl_name [, tbl_name] ...
```
